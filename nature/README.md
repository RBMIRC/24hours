# Nature : données écologiques

Copie des données de **Black Mountain Ecologies** (https://rbmirc.github.io/Black-Mountain-Ecologies/), au 3 novembre 2026 :

| fichier | contenu |
|---|---|
| `seasonal_calendar.json` | calendrier mois par mois : oiseaux, amphibiens, papillons, plantes en fleur, événements écologiques (décembre : 27 oiseaux, 5 amphibiens, hamamélis en fleur, fougères de Noël vertes, ours en torpeur) |
| `bmc_ecology_1933_1957.json` | année par année : météo, flore, faune (relevés GBIF), événements ; référentiel des espèces |
| `bmc_farm_1933_1957.json` | la ferme du collège : bêtes, cultures, bâtiments, matériel, personnes, état par année |

Sources déclarées par ces fichiers : NC Biodiversity Project, NC Native Plant Society, Coweeta LTER, iNaturalist, GBIF,
guides régionaux, Silver 2024, Western Regional Archives, BMC Museum + Arts Center.

Statut dans le scénario (décision du 3/11/2026) : les animaux et les plantes viennent de la **connaissance générale** du
milieu (Amérique du Nord, Caroline du Nord, Appalaches du Sud, saison, jour et nuit) ; part déduite 50-60 % pour une espèce
présente dans le calendrier de décembre, 40 % si un relevé de 1944 la signale, plus si l'on s'en écarte.
