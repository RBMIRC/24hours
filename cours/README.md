# Progression des cours — réservé

À traiter séparément. Chaque dossier de jour liste ses cours avec « *à compléter* » : ce que fait chaque cours ce
jour-là (séance, exercice, lecture, matériaux, œuvre en cours), d'après les fiches d'étudiants, les catalogues, les
témoignages et les synthèses de cours du semainier.

Organisation prévue : un fichier par cours et par trimestre, `cours/AAAA-AA/<enseignant>_<cours>.md`, séance par séance.
