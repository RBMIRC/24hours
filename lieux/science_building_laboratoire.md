# Science building / laboratoire

Motif de recherche dans les documents : `science (building|lab)|laboratoire`

## Laboratoire de chimie, sous l'entrée avant des Studies — été du récit
- **Description** : Labo décrépit, matériel rouillé et cassé ; abrite le still de Bert et une machine à laver de surplus militaire aux courts-circuits
- **Usages** : Distillation d'alcool illégal ; buanderie périlleuse (il faut s'asseoir sur la machine pendant l'essorage)
- *Source* : Rumaker 2003, p. 212

## Laboratoire photographique du collège — 
- **Usages** : Développement photographique
- **Ambiance** : Lieu de danger chimique : Cernovich y contracta une sévère intoxication aux métaux
- *Source* : BMCM+AC, Hazel Larsen Archer, p. 17

## Laboratoire de Natasha Goldowski — détruit fin septembre 1948
- **Description** : Bâtiment avec laboratoire de chimie-physique et chambre noire photographique
- **Usages** : Chimie, physique, photographie
- **Ambiance** : Incendie : chaîne de seaux remplis aux baignoires, portes improvisées, produits chimiques menaçant d'exploser
- *Source* : Duberman 1972, p. 318-319
